\# El Hareketleri ile Bilgisayar Kontrol Sistemi

Bu proje, kamera üzerinden el hareketlerini algılayarak bilgisayar kontrolü sağlayan bir sistemdir.

\## Proje Bileşenleri

\- Python ile el hareketi algılama ve bilgisayar kontrolü

\- SQL Server veritabanı

\- C# Windows Forms ile hareket kayıtlarını listeleme

\- Proje arayüz görselleri

\## Klasör Yapısı

\- `python/` : Python el kontrol sistemi kodları

\- `csharp-form/` : C# Windows Forms uygulaması

\- `database/` : SQL Server veritabanı script dosyası

\- `gorseller/` : Projeye ait ekran görüntüleri

\## Kullanılan Teknolojiler

\- Python

\- OpenCV

\- MediaPipe

\- PyAutoGUI

\- SQL Server

\- C# Windows Forms

cd python
